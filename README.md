# Jianhao Ma — Academic Website

Source for [jianhaoma.github.io](https://jianhaoma.github.io), built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll starter.

## Common updates

- Homepage biography and recruiting information: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- News: `_news/`
- CV page data: `_data/cv.yml`
- Downloadable CV: `assets/pdf/CV_jianhao.pdf`
- Contact and profile links: `_data/socials.yml`
- Site metadata and feature settings: `_config.yml`

Pushing to `master` triggers the GitHub Pages deployment workflow.
